# Architecture Decision Records

이 폴더는 프로젝트 진행 중 내린 주요 설계 결정을 짧게 기록합니다. 면접에서 "왜 이렇게 설계했는지" 설명할 근거 자료로도 사용합니다.

## 언제 ADR을 쓰나

- 여러 대안 중 하나를 선택했을 때 (예: 배포 플랫폼, 상태 머신 라이브러리 유무, confidence threshold 값)
- 나중에 "왜 이렇게 했더라?"가 궁금해질 만한 결정

## 형식

`NNNN-short-title.md` (예: `0001-monorepo-structure.md`)

```markdown
# NNNN. 제목

- 날짜: YYYY-MM-DD
- 상태: 제안됨 / 채택됨 / 폐기됨

## 배경
어떤 문제/선택지가 있었나

## 결정
무엇을 선택했나

## 이유
왜 선택했나 (트레이드오프 포함)

## 대안
고려했지만 선택하지 않은 것들과 이유
```
